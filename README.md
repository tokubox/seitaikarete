# こもれびカルテ

整体向け施術記録アプリのブラウザ試作です。スマホ・タブレット・PCに対応したカジュアルな画面を備えています。

## 起動

依存パッケージやビルドは不要です。

```sh
python3 -m http.server 8000 --directory dist
```

ブラウザで http://localhost:8000 を開きます。`dist/komorebi-demo.html` はCSSとJavaScriptをまとめた単体版です。暗号化機能にはWeb Crypto APIを利用できるHTTPSまたはlocalhost環境が必要です。

## 機能

- 顧客の登録・検索
- 人体図の前面・背面・側面切替と手書き
- 問診・安全確認の記録
- 施術メモと履歴
- AES-GCM / PBKDF2による暗号化エクスポート・復元

## 試作の制限

架空データによる操作確認用です。実際の個人情報は入力しないでください。通常のデータはメモリ内だけに保持され、再読込すると失われます。エクスポート対象は保存済みの記録で、下書きは含みません。

製品版の認証・端末上の暗号化永続保存・自動バックアップ・セキュリティ審査は未実施です。疾病の診断や治療方針の提案は行いません。AndroidアプリやChrome拡張機能としての配布は未対応です。

## ファイル

- `dist/index.html`: 画面とスタイル
- `dist/app.js`: 操作・記録・暗号化処理
- `dist/komorebi-demo.html`: 単体で持ち運べるHTML版
